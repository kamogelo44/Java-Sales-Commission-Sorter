# Employee Sales Commission Calculator (Java)

## Project Overview
A Java console application that calculates employee commissions based on total sales, sorts employees by sales performance using Bubble Sort, and displays the results before and after sorting.

Developed as part of the ITJVA2-12 module at Eduvos.

## Features
- Stores employee names and total sales in arrays.
- Calculates commissions based on tiered rates:
  - 3% for sales under R20,000
  - 5% for sales between R20,000 and R50,000
  - 9% for sales over R50,000
- Sorts employees by total sales using Bubble Sort.
- Displays a formatted table of results before and after sorting.
- Calculates and displays grand totals.
